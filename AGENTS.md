# Public REST and SOAP examples

Use the documented Python 3.11 environment and run `python -m pytest -q` for
affected changes. Keep launchers on loopback with the debugger off. Describe the
two independent services accurately; no forwarding layer is implemented.

Use synthetic events and plain language. Before publishing, review the diff,
files, dependency locks, links, commit metadata, and reachable history for
credentials and personal information. Never add real surveillance records or
customer endpoints. Use a GitHub noreply commit address. Pattern checks support
manual review; they do not certify that all sensitive information is absent.
